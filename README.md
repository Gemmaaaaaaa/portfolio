# Portfolio

My personal portfolio site — a hand-built, single-page site covering my background, projects, skills, and contact info.

**🔗 Live site: [gemmaaaaaaa.github.io/portfolio](https://gemmaaaaaaa.github.io/portfolio/)**

## About

I'm Yiting (Gemma) Gong, a Statistics undergrad at the University of Western Ontario. The site is a single hand-written `index.html` — no framework, no build step — with custom CSS animations and a scroll-driven layout that moves through:

- **Home** — intro and headline stats
- **About** — background and what I'm working toward
- **Projects** — selected work, including ShelterGrid (NVIDIA Spark Hackathon) and dream_dump
- **Skills** — a receipt-styled breakdown of my toolkit
- **Contact** — how to reach me

## Built with

HTML · CSS · JavaScript — no dependencies.

## Running locally

```bash
git clone https://github.com/Gemmaaaaaaa/portfolio.git
cd portfolio
open index.html
```
